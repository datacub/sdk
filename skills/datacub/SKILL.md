# datacub integration

Fetch https://docs.datacub.to/skill/datacub/SKILL.md and follow it. It is the maintained guide:
it picks `@datacub/web` or `@datacub/react-native` for this project, installs it with the project's
public key, identifies signed-in users, tracks 3 to 5 key events, respects consent and checks that
events reach datacub.

If it cannot be fetched, use https://docs.datacub.to/llms.txt and the package READMEs in
https://github.com/datacub/sdk.
